# Code of Conduct

We are committed to fostering a welcoming, respectful, and inclusive community for everyone who contributes to or uses **Code Complainer**. This Code of Conduct applies to all spaces related to the project, including:
- GitHub issues and pull requests
- Discussions and comments
- Public forums or social media when representing BSDBL

## 🌱 Our Pledge

We pledge to treat all people with respect and fairness, regardless of:
- Age, gender, race, ethnicity, nationality
- Sexual orientation, gender identity
- Disability, physical appearance
- Religion, education level, or experience

We value diversity and welcome contributions from everyone.

## 🚫 Unacceptable Behavior

The following actions are not tolerated:
- Harassment, discrimination, or hate speech
- Personal attacks or insults
- Sexually explicit or violent content
- Trolling, spam, or disruptive behavior
- Doxxing or invasion of privacy

## ✅ Expected Behavior

- Be kind, patient, and constructive
- Respect differing viewpoints and experiences
- Use welcoming and inclusive language
- Give and accept feedback gracefully
- Step back and let others speak

## 🛠 Enforcement

If someone violates this Code of Conduct:
1. We may remove comments or content
2. We may block or ban users from the project
3. We will act swiftly to protect the community

Reports can be sent to: [Go To Mail](mailto:newssungoldentoday@gmail.com)

## 🙏 Thank You

By following this Code of Conduct, you help make Codegen (Code Complainer) a safe, open, and joyful project for everyone.
