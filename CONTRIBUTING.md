# Contributing to Code Complainer (Codegen)

Thank you for considering a contribution to **Codegen (Code Complianer)**! Whether you're fixing a bug, adding a new block, or improving documentation, your help makes this project better.

We follow a simple, respectful process to keep development open and collaborative.

---

## 🛠️ How to Contribute

### 1. **Fork the Repository**
Click "Fork" on the [codegen](https://codeberg.org/BlueBix/codegen/)

### 2. **Clone Your Fork**
```bash
git clone https://codeberg.org/YOUR_USERNAME/codegen.git
cd bsdbl
```

### 3. **Create a Feature Branch**
Use a descriptive name:
```bash
git checkout -b feat/YOUR_BRANCH
# or
git checkout -b fix/YOUR_BRANCH
```

### 4. **Make Your Changes**
- Add or update code
- Include comments if needed
- Test your changes in the editor

### 5. **Commit Your Work**
Write a clear, concise message:
```bash
git commit -m "Your Commit message"
```

### 6. **Push to Your Branch**
```bash
git push origin feat/YOUR_BRANCH
```

### 7. **Open a Pull Request**
- Go to the [codegen](https://codeberg.org/BlueBix/codegen/)
- Click "Pull Requests" → "New Pull Request"
- Select your branch
- Describe your changes
- We’ll review and respond within 3-5 days

---

## 📝 Contribution Guidelines

- **Code Style**: Follow existing patterns in the codebase
- **Documentation**: Update `README.md` or add notes if needed
- **No Breaking Changes**: Avoid altering core behavior without discussion
- **Be Kind**: We follow a [Code of Conduct](CODE_OF_CONDUCT.md) — please be respectful

---

## 🐛 Reporting Bugs

Found a bug? Open an **Issue** with:
- A clear title
- Steps to reproduce
- Expected vs. actual behavior
- Browser and OS (e.g., Chrome on Linux)

---

## ✨ Suggesting Features

Have an idea? Open an **Issue** with:
- A clear description
- Use case or benefit
- Mockup (optional)

We’ll discuss and tag it as `enhancement`.
