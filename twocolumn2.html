Story About GitHub

GitHub is where you go to be seen. Codeberg is where you go to be consistent with your values.

1. Who owns it GitHub is owned by Microsoft since 2018. It's a for-profit corporation. Codeberg is a non-profit — Codeberg e.V., based in Germany. It's run by a registered association, funded by donations, not venture capital. No shareholders, no ads, no upselling to enterprise. For a lot of open-source purists, that matters. Git feels like it should live on non-corporate infrastructure.

2. The Copilot moment This was the breaking point for many. GitHub launched Copilot, an AI coder trained on public GitHub repos — including GPL-licensed code. Many developers felt their free, open-source work was being used to build a $10/month Microsoft product without consent, credit, or compensation. Codeberg explicitly says: We will not train AI on your code. We will not datamine your repos.

3. Open Source vs. Open Core Codeberg runs Forgejo, which is a community fork of Gitea, which is 100% free and open-source. GitHub itself is proprietary. You can't self-host GitHub. You can self-host Forgejo in 5 minutes on a Raspberry Pi. If you believe "we should use open-source tools to build open-source," GitHub is a contradiction. Codeberg lives that principle.

No tracking, no dark patterns GitHub has: • Extensive tracking • Required JavaScript • Pushed Copilot】 and Codespaces everywhere • Actions minutes, private repo limits, paywalls Codeberg has:• No tracking • No cookies banner needed because there are no trackers • CI included (Woodpecker CI) for free • Pages, issue tracker, everything you need, but very simple • Funded by the EU's Next Generation Internet program
